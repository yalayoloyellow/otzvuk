Описание того, что происходит внутри ядра на самом деле, по живому коду.

## 2. Главный принцип

Прибор не синтезирует сигнал — он численно решает эту схему, отсчёт за
отсчётом. Нигде в коде нет «частоты ноты»: частота получается сама, как
результат заряда конденсатора через резистор.

    вход блока (128 отсчётов при 48 кГц)
        │
        ▼
    ┌───────────────────────────────────┐
    │  на каждый отсчёт — ЧЕТЫРЕ шага   │   OVER = 4
    │  решателя при FS = 192 000 Гц     │   dt = 1/FS
    └───────────────┬───────────────────┘
                    ▼
    ┌───────────────────────────────────┐
    │  Баттерворт 4-го порядка          │   два биквада,
    │  срез 0.43·SR ≈ 20.6 кГц          │   Q = 0.5412 и 1.3066
    └───────────────┬───────────────────┘
                    ▼
              выход 48 кГц

Запас нужен не «для качества»: у прямоугольника с резким фронтом полоса
шире слышимой, и без запаса верхние гармоники заворачиваются вниз
негармоничным звоном. В железе Найквиста нет.


## 3. Экземпляр прибора: 221 число из семени

    семя ──► x₀
             │
             ├─► x₁ = (x₀ × 1664525 + 1013904223) mod 2³²  ──► x₁/2³² = доля
             ├─► x₂ = (x₁ × 1664525 + 1013904223) mod 2³²  ──► доля
             └─► …                                    всего 221 раз

    доля 0…1  ──►  номинал = мин + доля·(макс − мин)

Линейный конгруэнтный генератор. «Линейный» — формула прямая, `a·x + c`.
«Конгруэнтный» — от сравнения по модулю: всё живёт в остатках от деления
на 2³². Пара 1664525 / 1013904223 — известная, из Numerical Recipes, с
полным периодом 2³².

Приращение складывается **с произведением**, а не с множителем. Порядок
жёсткий: умножить, прибавить, взять остаток. Живой прогон с семени 12345:

    12345      → 87628868   → доля 0.020403
    87628868   → 71072467   → доля 0.016548
    71072467   → 2332836374 → доля 0.543156
    2332836374 → 2726892157 → доля 0.634904

Куда эти доли попадают — это допуски деталей, а не «настройки тембра»:

    C     8.2…12 нФ        керамика ±20%
    Ru    1.8…4.2 МОм      управляющий резистор
    Rвых  150…420 Ом       сопротивление открытого канала КМОП
    Rут   80…400 МОм       утечка платы: флюс, влага, монтаж
    Csv   0.6…4.5 пФ       паразитная ёмкость между дорожками
    Rсв   180…620 кОм      резистор кросс-связи
    Rтемн 4.0…5.4 МОм      фоторезистор в темноте
    Rсвет 40…60 кОм        он же на свету
    EMF   8.2…9.4 В        свежая «Крона»
    Rвн   2.5…26 Ом        внутреннее сопротивление батареи
    Cпит  1500…4700 мкФ    накопитель
    f0    420…1150 Гц      резонанс мембраны капсюля
    fКорп 74…165 Гц        резонанс коробки

Плюс оба порога каждого триггера по отдельности, показатель степени
фоторезистора, тепловые постоянные нити накала, добротности мод корпуса.
Для семени 12345 выпало: три голоса, ЭДС 8.96 В, капсюль 920 Гц, коробка
146 Гц.

Число голосов тоже из семени: жребий < 0.22 даёт два, < 0.72 — три, иначе
четыре. Диодная матрица рисунка (восемь вариантов), поворот рисунка и лень
счётчика на нечётных долях впаяны туда же: другой рисунок — другой прибор,
то есть Tab, а не ручка.


## 4. Узел-генератор

                    ┌──────────[ Rос ]──────────┐
                    │      (фоторезистор)       │
                    │                           │
     Vупр ──[ Rу ]──┤                           │
                    │                           │
     сосед ─[ Rсв ]─┼──────●──────► │⊳o│ ───────┴──────► выход
                    │      │       триггер Шмитта         │
     Vвх ──[ Rвх ]──┘      │       пороги ⅓ и ⅔ Vdd      │
                           │                              │
                 [ Rут ]  ═╪═ C                    [ Cмонтажа ]
                    │      │                              │
                    ⏚      ⏚                              ⏚
                                              ← отсюда конечная
                                                скорость фронта

Первый закон Кирхгофа — складываются проводимости всех ветвей:

    G  = 1/Rос + 1/Rу + 1/Rут + 1/Rсв + 1/Rвх
    Vэ = (Vвых/Rос + (Vупр+Vшум)/Rу + Vсоседа/Rсв + Vвх/Rвх) / G
    τ  = C / G

Шаг — точное решение, а не приближение:

    V ← Vэ + (V − Vэ)·e^(−dt/τ)

При постоянном Vвых ошибки нет вообще.

### Субсэмпловое переключение

    напряжение
       ▲
   ⅔Vdd├ ─ ─ ─ ─ ─ ─ ─ ─ ✕ ─ ─ ─    ← настоящее пересечение
       │                ╱ ┆              ВНУТРИ шага
       │            ╱     ┆
       │        ╱         ┆
       └────┬────────┬────┬────► время
          отсчёт   отсчёт │
                          └─ наивно переключили бы ЗДЕСЬ

Ошибка до 1/SR даёт девиацию δf/f ≈ f/SR — на 2 кГц около 4%, слышимо как
расстройка и грязь. Момент решается аналитически:

    t* = −τ · ln( (Vпорог − Vэ) / (V₀ − Vэ) )

Логарифм считается только когда порог действительно пройден, а проверяется
это одной уже посчитанной экспонентой: порог достигнут внутри шага тогда и
только тогда, когда к концу шага он уже пройден. Переключение приходит раз
в сотню-другую отсчётов, и логарифм на каждом стоил бы дороже всего
остального.

За один отсчёт допускается до четырёх переключений — быстрый узел успевает
щёлкнуть несколько раз внутри шага.

Триггер реагирует на УРОВЕНЬ, а не на пересечение: если напряжение уже за
порогом — он переключён, и точка. Прежний код ждал момента пересечения и,
проскочив его на старте, зависал навсегда.


## 5. Просадка питания и высота

           Vdd
            │
           ─┼─ ▼  защитный диод вверх
            │
    узел ───●
            │
           ─┼─ ▼  защитный диод вниз
            │
            ⏚

    V > Vdd  ⟹  V = Vdd + nVt·ln1p((V − Vdd)/nVt),   nVt = 45 мВ

Место, где первоначальный разбор ошибся, а численный эксперимент его
опроверг. Пороги триггера — доли Vdd, и кажется, что просадка обязана
двигать частоту. Но:

    T = RC · ln( (Vdd−Vn)·Vp / ((Vdd−Vp)·Vn) ),   Vp = ⅔Vdd,  Vn = ⅓Vdd
    ⟹  T = RC · ln 4

Vdd сокращается. Замер: при Vdd от 1.0 до 0.4 период не меняется вообще —
138.63 мкс во всех случаях.

Отсюда же нашлась настоящая ошибка. В коде стояло RC = 1/(1.2·f), где
1.2 — константа из даташита для РЕАЛЬНЫХ порогов конкретной микросхемы,
применённая к идеальным ⅓ и ⅔. Для них верно ln4 = 1.386.

    1.2 / 1.386 = 0.866  ⟹  −13.4%     (измерено −13.5…−14.0%)

### Чем же тогда слышна просадка

**Защитные диоды** (схема выше). Ток через диод растёт экспоненциально,
значит напряжение за шиной — логарифмически. Это единственная величина в
схеме, НЕ пропорциональная питанию — только благодаря ей просадка вообще
слышна.

**Схлопывание гистерезиса:**

      полное питание              на пределе

    Vdd ──────────────         Vdd ──────────────
    ⅔  ──────────╲                          ╲
                  ╲ узел                     ╳  пороги сошлись
                  ╱ ходит                    ╱
    ⅓  ──────────╱                          ╱
    0  ──────────────         0  ──────────────
       генерация идёт            СРЫВ

У КМОП-триггера петля держится, пока хватает усиления. На подходе к
пределу пороги сходятся к середине, и генерация не затихает, а
прекращается.


## 6. Шум: две природы

    ┌── тепловой (Джонсон) ──┐      ┌── избыточный токовый ──┐
    │  Vскз = √(4·k·T·R·Δf)  │      │  спектр 1/f            │
    │  микровольты           │  +   │  три полюса:           │
    │  плоский спектр        │      │  .00008/.0016/.032     │
    └───────────┬────────────┘      └──────────┬─────────────┘
                └────────────┬─────────────────┘
                             ▼
                     в ветвь [ Rу ] узла

Тепловой на слух почти не слышен. Но именно он не даёт двум периодам
совпасть в точности. Избыточный токовый шум углеродных резисторов на
порядки больше и даёт медленное дыхание частоты, по которому ухо отличает
живую схему от расчёта.

Теория говорит, что дрожание периода зависит от наклона кривой заряда в
точке решения:

       V ▲          пологo здесь ─► сильное дрожание
         │      ╭────────────────
         │    ╱
         │  ╱  круто здесь ─► дрожит слабо
         └──────────────────────► t

    σ_T ≈ σ_V · RC/(Vdd − Vпорог)

Это физическая причина того, что медленные генераторы дрожат сильнее
быстрых.

### Следствие для проверки

Шум тянется из Math.random(), который не сеется. Два прогона одного и того
же ядра расходятся ровно настолько же, насколько разные ядра. Побитово
сверять версии нельзя — только распределениями. Всякая сверка без
контрольного прогона «ядро с самим собой» здесь бессмысленна.


## 7. Связь генераторов и захват

Три механизма, и это не синонимы.

    (а) ДИФФУЗИОННАЯ — резистор между конденсаторами

        ●───[ R_c ]───●
        │             │
       ═╪═ C₁        ═╪═ C₂        связь ∝ разности напряжений
        ⏚             ⏚

    (б) ВЫНУЖДАЮЩАЯ — резистор от ВЫХОДА соседа к конденсатору

        │⊳o│ сосед ──[ R₂ ]──●──[ R₁ ]── свой выход
                             │
                            ═╪═ C
                             ⏚

        Vцель = (Vвых₁·R₂ + Vвых₂·R₁)/(R₁+R₂),   τ = C·R₁R₂/(R₁+R₂)
        сосед меняет И цель, И скорость заряда

    (в) ЧАСТОТНАЯ МОДУЛЯЦИЯ — не схемная связь вообще

        f ← f·(1 + k·x)          вибрато, боковые полосы, захвата нет

### Что показал замер

Разбор объявил (а) негодной. Развёртка числа вращения при K = 0.5 это
опровергла:

    расстройка:      1.00  1.15  1.35  1.50  1.75  2.00  2.40  3.00
    диффузионная:    1.00  1.00  1.26  1.43  1.69  1.95  2.33  3.00
    частотная:       1.00  1.14  1.34  1.50  1.75  2.00  2.37  2.90

При расстройке 1.15 диффузионная связь схлопывает отношение в 1.00, при
3.0 держит ровно 3.00. Частотная просто следует расстройке.

### Теория за этим

Отображение окружности:

    θₙ₊₁ = θₙ + Ω − (K/2π)·sin(2πθₙ)   (mod 1)

По теории число вращения ρ при K < 1 залипает на рациональных p/q — это
захват, устойчивая ритмическая фигура; области залипания расширяются с
ростом K и зовутся языками Арнольда, а при K > 1 они перекрываются и ρ
перестаёт быть определённым — хаос. Картина должна выглядеть так:

    ρ ▲
    2 ┤          ┌────────
      │        ╱
    1 ┤ ───────┘          ← ТАК ДОЛЖНО БЫТЬ по теории
      │
      └──────────────────► Ω

**Здесь надо быть точным в том, что доказано.** Измерен только захват, и
только при одном K = 0.5 — это строка чисел выше. Полная «чёртова
лестница» ρ(Ω) при разных K НЕ СТРОИЛАСЬ. Значит: захват в приборе есть и
измерен, а «языки Арнольда» — пока объяснение, а не результат. Утверждать
их по одной строке чисел нельзя.

### Что в коде

    узел ─────●───[ Rсв ]───► узел соседа      резистивная ветвь
              │                                 (входит в тот же G)
              ····[ Csv ]····► узел соседа      паразитная ёмкость
                                                ΔV = Csv·dVсоседа/C

Единицы пикофарад — дорожки на плате лежат рядом. Резистивная связь такого
же номинала просто не дала бы конденсатору дойти до порога.


## 8. Оптопара и шина питания

    управление ──►┌──────────┐
                  │  ЛАМПА   │  Vсвет 1.55…1.95 В
                  └────┬─────┘
                       ¦¦¦► свет
                  ┌────▼─────────────┐
                  │  ФОТОРЕЗИСТОР    │──── это Rос узла
                  └──────────────────┘

    R = Rтемн · exp( lnOpto · s^γ ),   s — освещённость
    темно 4.0…5.4 МОм  ←→  светло 40…60 кОм

Нить разогревается быстро, а остывает медленно: теплоёмкость одна, а
мощность подводится только при разогреве.

    яркость ▲
            │    ╱▔▔╲___
            │   ╱        ╲______
            └──────────────────────► t
              резко     долго

Отсюда несимметричная огибающая — качели взлетают резко и сползают долго,
и внизу, в области треска, прибор проводит больше времени, чем наверху.
Это не эффект, а теплофизика нити.

Та же оптопара работает беззвучным коммутатором: пока нить разогревается,
сопротивление сползает с мегаом до килоом, и ветвь ВЪЕЗЖАЕТ в суммирующий
узел, а не впрыгивает.

### Шина

    ЭДС ──[ Rвн·(1 + 14·(1−k)) ]──●───────────── ШИНА ─────┐
                                  │                        │
                             [ Cпит ]              ┌───────▼──────┐
                                  │                │   КАПСЮЛЬ    │
                                  ●                │  десятки мА  │
                                  │                └───────┬──────┘
                             [ Rразв ]                     │
                                  │                        │
                                  ●─── Vdd логики          │
                                  │    микроамперы         │
                             [ Cразв ] ◄── SAG убирает     │
                                  │                        │
                                  ⏚◄───── пульсация ───────┘

    C_бп · dVdd/dt = I_источника − Σ I_вентилей

Севшая батарея теряет не только вольты, но и жёсткость: внутреннее
сопротивление растёт в разы. У свежей кроны единицы ом, и шина при любом
накопителе стоит камнем. Замер: ручка накопителя меняла рябь с 0.19 до
0.05 В, то есть на два процента, — ни она, ни SAG слышны не были. У севшей
оживает всё разом.

Тумблер SAG убирает Cразв, и пульсация от тока капсюля доходит до порогов
триггеров. Прибор начинает модулировать сам себя. Вот откуда хрип в
самоделках; тепловой шум резистора тут ни при чём.

Выключение — не тишина, а разряд `dV/dt = −I/C`. Прибор оседает за доли
секунды, и оседает ПО ВЫСОТЕ: яркость лампы падает вместе с питанием,
фоторезистор темнеет, частота уходит вниз. Получается само.


## 9. Суммирующий узел и каскад

    выход 1 ──[ R₁ ]──┐
    выход 2 ──[ R₂ ]──┤
    выход 3 ──[ R₃ ]──┤
                      ├──● СУММИРУЮЩАЯ ТОЧКА
    микрофон ─[ Rм ]──┤  │      (ручка ПЕТЛЯ = этот резистор)
                      │  │
    перемычка ─[Rп]───┤  │      no-input: прошлый выход каскада
                      │  │
    палец ────[кожа]──┘  │
                         │
                    [ Cвых ]  4.7…22 мкФ
                         │
                   ┌─────▼─────┐
                   │  КАСКАД   │  U = (x − Cвых)·3.06
                   │           │  U ← (Vdd/2)·tanh(U/(Vdd/2))
                   └─────┬─────┘
                         ▼

    x = Σ Iᵢ / Σ Gᵢ

Не микшер, а пассивная цепь: резисторы на одну базу. Отсюда всё следует
само — петля не может перекричать прибор, потому что нагружает с ним один
узел и делит его; вой садится на резонансы капсюля и корпуса, потому что
идёт через них; порог самовозбуждения проходится плавно, потому что это
проводимость, а не ключ.

Разделительный конденсатор нужен потому, что перекошенный прямоугольник
несёт постоянную составляющую — без него диффузор уехал бы в упор.

Каскад питается от той же батарейки и больше неё выдать не может.
Упирается мягко, как настоящий транзистор.


## 10. Капсюль и корпус: откуда бас

              U от каскада
                   │
           ┌───────▼────────┐
           │ КАТУШКА        │   L 0.22…0.55 мГн
           │ L·dI/dt =      │   Bl 1.4…2.8 Тл·м
           │  U − I·R − Bl·v│   ← противо-ЭДС
           └───────┬────────┘
                   │  сила = Bl·I
           ┌───────▼──────────────────────┐
           │ МЕМБРАНА                     │  m 0.04…0.13 г
           │ m·ẍ = Bl·I − k(x)·x − c·ẋ    │  f0 420…1150 Гц
           │ k(x) = k₀·(1 + 1.8·(x/xmax)²)│  ход 0.05…0.16 мм
           └───────┬──────────────────────┘
                   │ 3-й закон Ньютона: привинчена
           ┌───────▼──────────────────────┐
           │ КОРОБКА                      │  fКорп 74…165 Гц

Прогрессивная жёсткость подвеса — не защита от перегруза, а устройство
подвеса; отсюда грязный низ на большом ходу.

Демпфирует диффузор не столько подвес, сколько сама катушка: двигаясь в
поле, она наводит ток, а тот тормозит движение. Сила этого торможения
равна Bl²/R и при обычных номиналах вдвое больше механической — вот почему
динамик звучит собранно почти при любом подвесе.

### Весь бас идёт от коробки

У мембраны низа нет физически — она для этого слишком лёгкая. Капсюль
привинчен к коробке и по третьему закону толкает её с той же силой, с
какой движется сам. Коробка тяжёлая и вялая, за щелчками не успевает — но
каждый щелчок её пинает, и она отзванивает своим низом.

Отношения мод нецелые: у струны обертоны целые, оттого она поёт ноту; у
пластины нецелые, оттого коробка не поёт, а бухает.

Отдаёт корпус СМЕЩЕНИЕМ стенки, а не скоростью: скорость шире по спектру и
тащит наверх то, что низом не является.

Ладонь бьёт широко и заводит все моды стенки; отдача капсюля сосредоточена
в точке крепления и низкочастотна — она гонит основную и почти не слышна
высшим. Оттого обычный звук от появления мод почти не изменился, а удар
стал деревянным вместо синусоидального.


## 11. Резонатор и метод интегрирования

    сила ▲
         │        ╱ линейная пружина
         │      ╱
         │    ╱╌╌╌╌╌╌  мягкая (β<0): частота падает с амплитудой
         │  ╱
         └──────────────► смещение
                    ↑ предел устойчивости |x| > √(α/|β|)

    ẍ + δẋ + αx + βx³ = F(t)
    ω(A) ≈ ω₀ · √(1 + 3βA²/(4α))

Формула подтверждена: расхождение с прямым интегрированием 0.1…1.5%.

### Что оказалось неверным в разборе

Обвинение «явный Эйлер накачивает энергию» преувеличено. В коде скорость
обновляется ПЕРЕД координатой:

    v ← v + a(x)·dt        а это уже полунеявная,
    x ← x + v·dt           симплектическая схема

Замер сохранения энергии за 20 000 шагов: при w=0.01 множитель ×1.004, при
w=0.05 ×0.980. Верле точнее (×1.000), но костыль-ограничитель нужен был не
из-за метода.


## 12. Алиасинг: не там, где думали

    ГЕНЕРАТОР                        НЕЛИНЕЙНОСТЬ
    период = целое число отсчётов    гармоники выше Найквиста
              │                                │
    зеркала ложатся ТОЧНО             зеркала падают МЕЖДУ
    на гармоники                      гармоник → звон
              │                                │
        алиасинг 0.0%                    до 51% мусора

    основная 1109 Гц:  tanh 0.0%   sin×5  0.3%   sin×9  0.0%
    основная 3457 Гц:  tanh 1.5%   sin×5  0.3%   sin×9 42.1%
    основная 6211 Гц:  tanh 3.9%   sin×5 14.2%   sin×9 51.0%

У самого генератора алиасинга нет вовсе. Побочный эффект того же —
квантование частоты к сетке SR/n:

    3000 → 2400 (=48000/20),  6000 → 4800 (=48000/10),  9000 → 6000 (=48000/8)

Шаг сетки растёт квадратично с частотой. Субсэмпловое переключение (§4)
это и снимает.

Природа гармоник разная: tanh сжимает спектр и даёт только нечётные,
чётные появляются при смещении; сворачивание синусом даёт спектр по
функциям Бесселя, и ширина растёт с глубиной — взрывное обогащение.

Никаких семплов и приклеенных слоёв. Логика на каждом шаге КОММУТИРУЕТ
НОМИНАЛЫ САМОГО ПРИБОРА. Звучит всё тот же прибор, просто его дёргают по

Рисунок евклидов, по алгоритму Бьорклунда: k ударов расставляются по n

метроном. Грув сдвигает нечётные доли назад по времени — снято с живых
барабанщиков.

## 15. Как это меряется

    ┌─────────────────┐        ┌──────────────────────┐
    │ chaos.worklet.js│───────►│ СТЕНД                │
    │ (текст файла)   │ подмена│ свой решатель,       │
    └─────────────────┘ якорей │ свои формулы,        │
                               │ написан ОТДЕЛЬНО     │
                               └──────────┬───────────┘
                                          ▼
                                   сверка распределений

Стенды написаны отдельно от движка: проверять код им же самим — значит
проверять его собой. Каждый загружает ядро как текст, при необходимости
подменяет якоря в исходнике (чтобы сравнить две версии) и гоняет блоки
напрямую, без звуковой карты.

Из принципов, которые дались дорого:

- **Сначала проверить показометр, потом чинить по нему.** Детектор атак
  врал разбросом 0.26 при нулевой дрожи; метрика формы клэпа при одном
  разряде насчитывала четырнадцать. Врущий показометр хуже отсутствующего.

- **Регрессия только распределениями** (§6). Контрольный прогон «ядро с
  самим собой» задаёт мерку, в которую чужое ядро обязано лечь.

- **Перебор находит то, чего не составить руками.** Зависание при плавном
  переходе нашлось за один заход из тридцати двух случайных пар сборок:
  ведение тянуло число голосов дробным, cells[1.37] не существует, воркл
  умирал молча. Семь падений — у всех семи включён BEND.
