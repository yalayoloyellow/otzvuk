# отзвук

Шумовой синтезатор, смоделированный на уровне схемы. Три релаксационных
генератора на КМОП-триггерах, качели с оптопарами, суммирующий узел, каскад с
мягким ограничением, капсюль с корпусом. Расчёт посэмпловый. Номиналы деталей
выводятся из семени сборки: у каждой коробки свои допуски, пороги и монтаж.

Интерфейс — текстовый: моноширинный шрифт, знакоместа, без графики. Кегль
зависит от размера окна.

## Установка

Прибору нужно отдельное окно. Во вкладке браузера часть клавиш до него не
доходит: Tab и сочетания с ним браузер обрабатывает сам.

**Компьютер.** Скачать репозиторий, перетащить `otzvuk.app` на рабочий стол
или положить туда ссылку на него. По клику открывается окно без вкладок и
адресной строки. Сервер поднимается автоматически, если не запущен. Путь
вычисляется от расположения самого файла, поэтому папку можно переносить.

То же вручную:

    python3 serve.py --okno

**Телефон.** <https://yalayoloyellow.github.io/otzvuk/>

Открыть и добавить на устройство: iOS — «Поделиться» → «На экран Домой»,
Android — меню браузера → «Установить приложение». Значок открывает прибор
отдельным окном. После первого открытия сеть не нужна: файлы хранятся на
устройстве.

По той же ссылке прибор работает и во вкладке браузера — с оговоркой про
клавиши выше.

**Различия.** Локальный вариант пишет звук на диск и хранит пресеты; за это
отвечает `serve.py`. Установленный по ссылке этого не умеет. Сетевых запросов
нет ни в том, ни в другом случае.

Первое нажатие любой клавиши включает питание. Накопитель заряжается броском
тока — это слышно.

## Управление

**Ручка — одна клавиша, значение ведут стрелки.** Держишь букву — ручка
выбрана; `←` и `→` ведут значение, `⇧` вдесятеро, `⌘` втрое. Две зажатые
буквы едут от одной стрелки.

**Тумблеры — `⇧` и та же буква.** Стрелка без зажатой буквы не делает ничего.

**Цифровой ряд — площадки.** Двенадцать точек схемы: три узла заряда, три
выхода генераторов, узел качелей, узел гула, суммирующая точка, накал лампы,
шина, общий провод. Палец соединяет их через тело; две площадки разом дают
перемычку между двумя точками схемы. Диапазон — больше четырёх октав.

**Пробел — ладонь на корпусе.** Переходное сопротивление всех касаний падает
на порядок.

**`⇧v` METAL** — вместо пальца отвёртка: сопротивление контакта ниже ещё на
порядок.

    ⌥m      микрофон            ⌥⇧m    звук системы
    ⌥f      дорожка по кругу    `      запись в WAV
    ⌥←→     листать пресеты     ⌥↑↓    сохранить / удалить
    tab     пересобрать         ⇧tab   назад по сборкам
    ⌥p      пометить явление    ⌥b     быстрый щуп

## Движение — розовая зона

**`y` BEND** — самый быстрый генератор ведёт двух других через резисторы в их
конденсаторы; ведомые садятся на целые доли его частоты.

**`⇧y ⇧u ⇧i` HOLD** — ключ размыкает цепь заряда своего медленного узла: слой
останавливается в текущем положении.

**`u` SYNC** — качели садятся на целую долю сигнала на входе (микрофон,
система, дорожка). Ряд делений: полдоли, доля, две, три, пять.

**`i` SPLAY** разводит три медленных узла по разным делениям: один слой на
долю, другой на две, третий на четыре.

**`o` SLIP** — слои разведены на доли процента и на свободном ходу расходятся
по фазе. С SYNC работает в противоход: захват чужого ритма останавливает
дрейф.

**`p` TILT** — слои расходятся по характеру: первый глубже в треск, третий
поднят над ним.

## Резак и окрас — красная зона

**`b` — темп рукой.** Несколько нажатий в долю задают темп метронома. Под
входной сигнал он не подстраивается.

**`c` CHOP** — повтор начала доли по метроному. Ряд: 1/2, 1/4, 1/8, 1/16 доли.

**`v` SCREW** — чтение отстаёт от записи до половинной скорости, высота
падает. Сброс на каждой доле удерживает такт.

**`.` COLOR, `⇧b` PROFILE** — эквализация к профилю шума: восемь октавных
полос сводятся к белому, розовому или коричневому. У розового энергия всех
октав равна.

## Внешний звук внутрь схемы

Любой звук — музыка, видео, другой синтезатор — заводится внутрь схемы. Он не
подмешивается к выходу, а участвует в формировании волны.

Ручка `ROUTE` выбирает точку подключения:

    накал   светит огибающей источника; сам источник не слышен
    узлы    ток в частотозадающие конденсаторы: деление входа на целые
    шина    качает питание: захват по высоте входа

В положении «узлы» три генератора садятся на разные целые деления одного
источника — 1/3, 1/5, 1/7.

### Настройка на macOS

Браузер на macOS отдаёт звук только одной вкладки; системный звук недоступен.
Нужен виртуальный звуковой кабель.

Скрипт `настройка.command` из этой папки ставит BlackHole, снимает глушение с
динамиков и переключает выход. Вручную:

1. `brew install blackhole-2ch`
2. `sudo killall coreaudiod`
3. В настройках звука выбрать выходом BlackHole 2ch
4. В приборе нажать `⌥⇧m`

Прибор переключается с виртуального выхода на физические колонки, иначе он
играл бы сам себе в петлю. Слышно только то, что прошло через схему.

Чтобы слышать оригинал и обработку одновременно, соберите в «Настройке
Audio-MIDI» устройство с несколькими выходами из динамиков и BlackHole и
выберите его выходом. При таком выходе клавиши громкости не работают:
громкость регулируется на странице самих динамиков.

Браузер запросит доступ к микрофону — отдельного разрешения для виртуального
входа в вебе нет, любой вход называется микрофоном.

## Замер

`zamer.js` снимает сырые числа: моменты спектра, плоскостность,
треть-октавная сетка, вершины списком, кривые модуляции. Без интерпретации.

`Device.snimok` — щуп на схему, более ста величин: ток по каждой ветви
каждого узла, равновесная цель, постоянная времени, оба порога, запас до
срыва.

Стенды `stend_*.mjs` сверяют расчёт с формулой: период одиночного генератора
сходится с аналитическим до тысячных долей процента.
