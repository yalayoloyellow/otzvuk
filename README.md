# отзвук

Шумовой синтезатор. Схемная модель: три релаксационных генератора на
КМОП-триггерах, качели с оптопарами, суммирующий узел, каскад с ограничением,
капсюль с корпусом. Расчёт посэмпловый, номиналы деталей выводятся из семени
сборки. Интерфейс текстовый.

## Установка

Компьютер: скачать репозиторий, положить `otzvuk.app` на рабочий стол. Клик
открывает окно без вкладок, сервер поднимается сам. То же вручную:

    python3 serve.py --okno

Телефон: <https://yalayoloyellow.github.io/otzvuk/> → «На экран Домой» (iOS)
или «Установить приложение» (Android). После первого открытия работает без
сети.

Во вкладке браузера Tab и сочетания с ним до прибора не доходят.

Запись звука на диск и пресеты есть только в локальном варианте. Сетевых
запросов нет ни в одном.

Питание включается первым нажатием любой клавиши.

## Управление

    держать букву + ← →     вести ручку        ⇧ вдесятеро, ⌘ втрое
    ⇧ + буква               тумблер
    1…0 - =                 площадки, 12 точек схемы
    пробел                  ладонь на корпусе
    tab / ⇧tab              пересобрать / назад по сборкам
    ⌥m / ⌥⇧m                микрофон / звук системы
    ⌥f                      дорожка по кругу
    `                       запись в WAV
    ⌥← →                    листать пресеты
    ⌥↑ ↓                    сохранить / удалить пресет
    b                       темп рукой; b + ← → правит число
    g                       фраза: держать — запись, отпустить — петля
    ⌥p / ⌥b                 пометить явление / быстрый щуп

Две зажатые буквы едут от одной стрелки. Стрелка без буквы не делает ничего.

## Площадки

Двенадцать точек схемы: три узла заряда, три выхода генераторов, узел
качелей, узел гула, суммирующая точка, накал лампы, шина, общий провод. Две
площадки разом дают перемычку между двумя точками. Диапазон больше четырёх
октав.

## Вход

ROUTE выбирает точку подключения внешнего сигнала:

    lamp    огибающая источника светит на оптопары; источник не слышен
    nodes   ток в частотозадающие конденсаторы; деление входа на целые
    rail    качание питания; захват по высоте входа

В положении nodes три генератора садятся на разные деления одного источника:
1/3, 1/5, 1/7.

## Звук системы на macOS

Браузер отдаёт звук только одной вкладки. Нужен виртуальный кабель.

Скрипт `настройка.command` ставит BlackHole, снимает глушение с динамиков и
переключает выход. Вручную:

1. `brew install blackhole-2ch`
2. `sudo killall coreaudiod`
3. Выход системы — BlackHole 2ch
4. В приборе `⌥⇧m`

Прибор играет в физические колонки, минуя виртуальный выход. Чтобы слышать
одновременно оригинал и обработку, соберите в «Настройке Audio-MIDI»
устройство с несколькими выходами. При таком выходе клавиши громкости не
работают.

Браузер запросит доступ к микрофону: отдельного разрешения для виртуального
входа в вебе нет.
