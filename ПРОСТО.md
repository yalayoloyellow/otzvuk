# ПРОСТО: как это работает

Без формул, со схемами. Если хочется математики — она в УСТРОЙСТВО.md.

Обозначения на схемах:

    ─[ R ]─   резистор (сопротивление, «тонкая струйка»)
    ═╪═       конденсатор (копит заряд, «бачок»)
    ⏚         общий провод, «земля»
    │⊳o│      триггер Шмитта (переключатель с двумя порогами)
    ──►       куда течёт


## Весь прибор одной картинкой

    ┌─ КРОНА ─[Rвн]─┬───── шина питания ─────────────────┐
    │               │                                    │
    │             [Cпит]                                 │
    │               │                                    │
    │            [Rразв]──┬── питание логики             │
    │               │  [Cразв]                           │
    ⏚               ⏚     ⏚                              │
                                                         │
        ┌─────────┐   ┌─────────┐   ┌─────────┐          │
        │ ГОЛОС 1 │═══│ ГОЛОС 2 │═══│ ГОЛОС 3 │          │
        └────┬────┘   └────┬────┘   └────┬────┘          │
             │             │             │               │
           [R1]          [R2]          [R3]              │
             └─────────────┴─────────────┘               │
                           ●  суммирующая точка          │
                           │                             │
                      [Cвых]                             │
                           │                             │
                     ┌─────▼─────┐                       │
                     │  КАСКАД   │  транзистор           │
                     └─────┬─────┘                       │
                           │                             │
                     ┌─────▼─────┐                       │
                     │  КАПСЮЛЬ  │──── ток обратно ──────┘
                     └─────┬─────┘     (качает шину!)
                        привинчен
                     ┌─────▼─────┐
                     │  КОРОБКА  │
                     └─────┬─────┘

Дальше — по узлам.


## Главный фокус

Обычный синтезатор рисует звуковую волну по формуле: «мне нужна нота ля,
значит колеблюсь 440 раз в секунду».

Этот — не рисует. Внутри него **посчитана электрическая схема**, деталь за
деталью. Компьютер **сто девяносто две тысячи раз в секунду** решает
задачку «сколько сейчас вольт в каждой точке этой схемы».

Звук получается сам, как побочный результат. Нигде в коде не написано
«частота». Частота выходит из того, как быстро наполняется конденсатор.


## Откуда берётся звук

Вот он, весь генератор. Одна деталь, один конденсатор, одно сопротивление:

              ┌──────────[ Rос ]──────────┐
              │                           │
              │                           │
         ─────●───────────► │⊳o│ ─────────┴────► выход
              │            триггер
             ═╪═ C          Шмитта
              │
              ⏚

Читается так. Выход триггера через резистор `Rос` заряжает конденсатор
`C`. Конденсатор наполняется. Как только напряжение на нём доходит до
**верхнего порога**, триггер переключается — и теперь тот же резистор
конденсатор **разряжает**. Дошло до **нижнего порога** — переключился
обратно. И так вечно.

Представь бачок унитаза:

    конденсатор  = бачок       копит электричество
    резистор     = струйка     чем тоньше, тем дольше наполняется
    триггер      = поплавок    щёлкает на верхнем и нижнем уровне

Щёлк-щёлк-щёлк — это уже колебание. Двести раз в секунду — низкое
гудение. Две тысячи — писк.

**Толще струйка — выше звук. Тоньше — ниже.** Всё.

А вот тот же узел, но со всеми ветвями, которые в него втекают на самом
деле:

              ┌──────────[ Rос ]──────────┐
              │                           │
    Vупр ──[ Rу ]──┐                      │
                   │                      │
    сосед ──[ Rсв ]┼──●──► │⊳o│ ──────────┴────► выход
                   │  │
    палец ──[ кожа ]  │
                     ═╪═ C
                      │
                      ⏚

Все они спорят за одну точку. Кто сильнее тянет — тот и решает, куда она
поедет. Из этого спора и получается звук.


## Почему их три

Один бачок — скучная пищалка. В приборе их **два, три или четыре** (сколько
именно — решает семя), и между ними есть тоненькие связи:

       ГОЛОС 1              ГОЛОС 2              ГОЛОС 3
          │                    │                    │
          ●────[ Rсв ]─────────●────[ Rсв ]─────────●
          │                    │                    │
          │·····[ Csv ]········│·····[ Csv ]········│
          │   паразитная       │                    │
         ═╪═   ёмкость        ═╪═                  ═╪═
          │    дорожек         │                    │
          ⏚                    ⏚                    ⏚

Две разные связи, и обе настоящие:

- **`Rсв`** — резистор. Постоянно подтягивает соседние бачки друг к другу.
- **`Csv`** — паразитная ёмкость. Дорожки на плате просто лежат рядом, и
  когда сосед щёлкает, через неё перескакивает капелька заряда. Никто её
  не ставил специально, она получается сама от монтажа.

И вот тут начинается интересное. Поставь несколько метрономов на одну
доску — через минуту они застучат вместе. Они слышат друг друга через
доску и подстраиваются.

Бачки делают то же самое. Они то расходятся, то **схватываются в ровное
отношение**: один щёлкает ровно вдвое чаще другого, или втрое.

    расстройка:  1.00  1.15  1.35  1.50  1.75  2.00  2.40  3.00
    что вышло:   1.00  1.00  1.26  1.43  1.69  1.95  2.33  3.00
                       ↑                                   ↑
                  схватились                          схватились

**Отсюда берётся ритм.** Его никто не программировал, он возникает сам из
того, что генераторы друг друга слышат.

А если связь сделать слишком сильной — они срываются в хаос. Между
порядком и хаосом там узкая полоска, и вся музыка живёт в ней. Ручка BEND
как раз и меняет толщину этих связей.


## Лампочка вместо ручки

Как менять толщину струйки на ходу? В таких приборах делали хитро:

    управление ──►┌─────────┐
                  │ ЛАМПОЧКА│
                  └────┬────┘
                       ¦
                       ¦ свет
                       ¦
                  ┌────▼─────────┐
                  │ ФОТОРЕЗИСТОР │──── это и есть Rос генератора
                  └──────────────┘

                  темно  → 4…5 МОм → бачок наполняется еле-еле → треск
                  светло → 40…60 кОм → наполняется быстро → писк

Фоторезистор пропускает ток тем лучше, чем ярче на него светят. Ярче свет
— толще струйка — выше звук.

Тут важна мелочь, которая слышна ушами. **Лампочка загорается быстро, а
гаснет медленно** — нить накаливания остывает не сразу:

    яркость
      ▲
      │      ╱▔▔▔▔╲
      │     ╱       ╲___
      │    ╱             ╲______
      │   ╱                     ╲________
      └───────────────────────────────────► время
          резко              долго и вязко

Поэтому звук взлетает резко, а сползает вниз долго. И внизу, в области
треска, прибор проводит **больше времени, чем наверху**. Это не эффект,
который кто-то придумал. Это просто так остывает проволочка.


## Батарейка тоже играет

    ЭДС 8.2…9.4 В
        │
      [ Rвн ]  2.5…26 Ом — у СЕВШЕЙ батарейки вырастает в 15 раз
        │
        ●──────────── шина ──────────────┐
        │                                │
     [ Cпит ]                      ┌─────▼─────┐
     1500…4700 мкФ                 │  КАПСЮЛЬ  │  десятки мА
        │                          └───────────┘
        ●                                 ▲
        │                                 │
     [ Rразв ]                             дёргает шину
        │
        ●──────── питание логики ── микроамперы
        │
     [ Cразв ]  ◄── тумблер SAG выкидывает ЭТОТ конденсатор
        │
        ⏚

Все детали висят на одной батарейке, и **динамик жрёт в тысячу раз больше,
чем вся логика**.

Значит: динамик дёрнулся — батарейка на миг просела — генераторы это
почувствовали и сбились. Прибор **сам себя модулирует**. Вот откуда хрип у
самодельных коробок.

Конденсатор `Cразв` для того и стоит, чтобы эту грязь до логики не
пускать. Тумблер SAG его убирает — и связь становится грубой и слышной.

**Севшая батарейка** — это не просто «тише». У свежей внутреннее
сопротивление единицы ом, и шина стоит камнем, трястись ей нечем. У севшей
оно в разы больше, и шина начинает ходить за звуком.

**Выключение** — тоже не тишина, а разряд:

    выключил ──► батарейки в цепи нет, но Cпит заряжен
                 схема живёт на нём и высасывает досуха

    громкость  ▔▔▔╲___
    высота     ▔▔▔╲___   ← лампочка гаснет, фоторезистор темнеет
                            частота уползает вниз

Прибор **оседает**, а не смолкает. Полсекунды. Никто этого не писал —
получилось само.


## Динамик маленький, а бас откуда?

    ──[ Cвых ]──►┌──────────┐
                 │  КАСКАД  │  транзистор, упирается мягко
                 └────┬─────┘
                      │ U
                 ┌────▼──────────────────┐
                 │  катушка:  L, R, Bl   │
                 └────┬──────────────────┘
                      │ сила = Bl·I
                 ┌────▼──────────────────┐
                 │  МЕМБРАНА             │  масса 0.04…0.13 г
                 │  m, пружина k, трение │  свой резонанс 420…1150 Гц
                 └────┬──────────────────┘
                      │ привинчена  ← третий закон Ньютона
                 ┌────▼──────────────────┐
                 │  КОРОБКА              │  74…165 Гц
                 │  мода 1  ×1           │
                 │  мода 2  ×2.2…2.9     │  отношения НЕЦЕЛЫЕ
                 │  мода 3  ×3.9…5.4     │
                 │ (мода 4  ×5.5…13 — железка на корпусе)
                 └────┬──────────────────┘
                      ▼ звук

Внутри стоит **телефонный капсюль** — такая же штука, как в старой трубке.
Мембранка лёгкая, крошечная. Низких частот она отдать **не может
физически**: слишком лёгкая, ей нечем толкать воздух так медленно и мощно.

Но капсюль привинчен к коробке. Мембрана дёрнулась вперёд — коробка
получила толчок назад. Каждый щелчок пинает коробку.

Коробка тяжёлая и неповоротливая. За быстрыми щелчками не успевает —
**зато гудит на своей собственной ноте**, где-то между 74 и 165 герцами.

**Весь бас прибора — это гудящая коробка.** Как у гитары: струна сама по
себе тихая и тонкая, а звучит дека.

Гудит она не чисто. У струны обертоны целые — оттого она поёт ноту. У
пластины нецелые — оттого коробка не поёт, а **бухает**. А если к корпусу
привинчена железка, добавляется долгий металлический звон.


## Двенадцать пятачков и палец

Цифры `1…0`, `-`, `=` — это **двенадцать оголённых пятачков на плате**.
Нажал — приложил палец:

    пятачок ──[ кожа: 0.62…0.85 МОм сухая ]──┐
                     0.24…0.38 МОм влажная   │
                                             │
    ладонь на корпусе ──[ 0.45…1.1 МОм ]─────┴──► ⏚
                    ¦
                    ¦ плюс ёмкость всей ладони над платой
                    ¦ (14…45 пФ к КАЖДОЙ дорожке)
                    ▼
             слегка ведёт ВСЕ генераторы, а не только тот, что нажат

Цепь должна куда-то замкнуться — поэтому ладонь на корпусе тут не
украшение, а обязательная половина. Без неё одиночное касание не значило
бы ровно ничего.

Пробел — ладонь плотно. Шифт-V — трогать не пальцем, а **отвёрткой**:
металл проводит куда лучше кожи, и звук уходит гораздо дальше.


## Почему каждый прибор свой

У прибора есть **семя** — просто число.

    семя 12345
        │
        ▼  формула: (число × 1664525 + 1013904223), взять остаток
        │
        ├──► 0.020 ──► ЭДС батарейки      8.96 В
        ├──► 0.017 ──► внутреннее сопр.   тут-то ом
        ├──► 0.543 ──► конденсатор №1     10.3 нФ
        ├──► 0.635 ──► конденсатор №2     ...
        │       ...
        └──► всего 221 число: все детали разом

Это не «настройки тембра». Это **допуски**, как на настоящем складе
радиодеталей: резисторы бывают ±5%, керамика ±20%, микросхемы из разных
партий. Спаяешь две одинаковые схемы — они зазвучат по-разному.

Тут то же самое. Нажал Tab — собрался **другой физический прибор**. Не
другой пресет, а другая коробка, спаянная из других деталей: другое число
голосов, другая коробка, другой рисунок в счётчике.

Формула жёсткая, поэтому одно и то же семя **всегда** даёт один и тот же
прибор. Понравился звук — записал число, вернулся к нему через год.


## Откуда ритм

    ┌───────────┐   ┌──────────────┐   ┌─────────────────┐
    │ тактовый  │──►│ счётчик ÷16  │──►│ диодная матрица │
    │ генератор │   │ 16 шагов     │   │ (впаяна в этот  │
    └───────────┘   └──────────────┘   │  экземпляр!)    │
                                       └────────┬────────┘
                                                │
                             коммутирует ───────┼──► яркость лампы
                                                └──► питание

Никаких сэмплов и никаких приклеенных слоёв. Счётчик на каждом шаге
**дёргает номиналы самого прибора**. Звучит при этом всё тот же прибор,
просто его трясут по рисунку.

Рисунок — евклидов: скажем, пять ударов расставить по шестнадцати шагам
максимально ровно. Такие сетки слышатся музыкой, а не метрономом.


## Чего внутри точно нет

- **Нет сэмплов.** Ни одной записи. Всё считается на лету.
- **Нет нот и гамм.** Прибор не знает, что такое до-диез.
- **Нет генератора синуса.** Единственный источник звука — щёлкающие
  бачки и гудящая коробка.
- **Нет случайности в сборке.** Семя решает всё до последнего резистора.

Случайность есть ровно в одном месте: **тепловой шум резисторов**. Он
настоящий, посчитанный по физической формуле, и он крошечный. Но именно
из-за него два периода никогда не совпадают в точности — и прибор звучит
живым, а не механическим.


## Одно следствие, ради которого всё это стоило делать

Раз прибор — это схема, а не набор эффектов, он умеет ломаться
**по-настоящему**.

Прикрути питание — и посмотри, что делают пороги триггера:

    полное питание          питание на пределе

    Vdd ─────────────       Vdd ─────────────
    ⅔ ──────────╲                        ╲
                 ╲ бачок                  ╳  пороги сошлись
                 ╱ ходит                  ╱  бачку некуда ходить
    ⅓ ──────────╱                        ╱
    0  ─────────────        0  ─────────────
       генерация идёт          СРЫВ: элемент замолчал

Генерация не затихает плавно — она **прекращается**. У логики схлопывается
рабочая петля, и элемент просто перестаёт щёлкать.

Перегрузишь коробку — низ начнёт рычать, потому что подвес динамика
упирается в край хода. Уберёшь развязку — прибор загудит сам на себя.

Ни одно из этих поведений не написано отдельной строчкой. Они выпадают из
физики сами, и поэтому их **нельзя подделать**.
